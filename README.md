# Employee Shift Management System

A web-based Employee Shift Management System designed to simplify workforce scheduling and attendance management.

## Features

* Employee & department management
* Availability tracking
* Static and rotation shift assignment
* Weekly schedule generation
* Attendance tracking
* Professional Excel export
* Dynamic shift coloring
* Department-based grouping
* Smart validation before export

## Use Case

Originally built to solve a real scheduling workflow that was managed manually using Excel sheets.
